# proximity_voip_3d
Sistema de voz posicional en tiempo real. Captura audio del micrófono a 16 kHz Mono en paquetes PCM de 960 bytes, incorpora buffer de desjitter (jitter buffer) para tolerar fluctuaciones de red, y aplica atenuación 3D realista con emisión de niveles de volumen para que la IA enemiga reaccione a los gritos.
